# berimor-skills

Пакеты поведения (**скилы**) для [berimor](https://github.com/devpilgrin/berimor) —
детерминированного agentic CLI. Скил — это декларативный пакет: что умеет,
когда применять, какие инструменты разрешены. Выбор скилла по триггерам —
кодом, не моделью (архитектурный принцип berimor: решения — детерминированный
код, модели — исполнители).

## Формат

```
skills/<name>/
├── SKILL.md        # YAML frontmatter + тело (инструкции модели)
└── scripts/        # опционально: вспомогательные скрипты скилла
```

### SKILL.md

````markdown
---
name: code-review-ru
version: 0.1.0
description: Ревью diff'ов на русском — стиль, ошибки, риски
triggers:
  - "проверь код"
  - "ревью"
  - "/review"
tools:              # потолок инструментов скилла (пересечение с гейтом)
  - files.read
  - files.list
  - terminal.exec
model_tier: strong  # минимальный класс модели (weak|strong)
---

# Инструкции для модели

(Тело — системный контекст, который получает модель, когда скилл активен.)
````

Правила:

- `tools` — **потолок, не расширение**: скилл не может получить инструмент,
  которого нет у сессии; пересечение вычисляет детерминированный код.
- `triggers` — точные фразы и slash-команды; совпадение ищет код, не модель.
- Секретов в скилле нет и не будет — маскировщик на границах обязателен.

## Содержимое каталога

**Работа с кодом:**

| Скилл | Описание |
|---|---|
| `code-review-ru` | Ревью diff'ов: стиль, ошибки, риски безопасности |
| `security-audit-ru` | Быстрый security-проход по diff/файлу — OWASP-классы проблем |
| `bug-triage-ru` | Триаж бага: воспроизведение → локализация причины → точечный фикс |
| `test-writer-ru` | Тесты для существующего кода по поведению, с граничными случаями |
| `commit-msg-ru` | Сообщение коммита по staged-диффу: что и зачем, не пересказ |

**Документы** (адаптировано из anthropics/skills; скрипты исполняются на машине пользователя):

| Скилл | Описание |
|---|---|
| `docx` | Документы Word (.docx/.dotx): создание, чтение, правка, tracked changes |
| `xlsx` | Электронные таблицы (.xlsx/.csv/.tsv): формулы, форматирование, очистка данных |
| `pptx` | Презентации (.pptx/.potx): создание и редактирование деков |
| `pdf` | PDF: чтение и извлечение, объединение/разделение, формы, OCR сканов |

**Экосистема агента:**

| Скилл | Описание |
|---|---|
| `mcp-builder` | Построение MCP-серверов (Python FastMCP / Node SDK) — от дизайна инструментов до упаковки |
| `skill-creator` | Создание и улучшение скиллов, измерение их эффективности (evals) |

**Коммуникация и дизайн:**

| Скилл | Описание |
|---|---|
| `doc-coauthoring` | Соавторство документации: структурированные итерации с пользователем |
| `internal-comms` | Внутренние коммуникации: статус-отчёты, 3P-апдейты, FAQ, инциденты |
| `frontend-design` | Осознанный визуальный дизайн UI: эстетика, типографика, без шаблонности |

## Установка

Каталог по умолчанию зашит в berimor: из чата — `/skills add` (пикер
покажет доступное из этого репозитория), из CLI — `berimor skill install
<name>` (например `berimor skill install code-review-ru`). Любой другой
источник: `berimor skill install <name> --from <git-url>` или клонирование
в `~/.config/berimor/skills/` (глобально) либо `.berimor/skills/` (проект,
сильнее глобальных). Список доступного в каталоге: `berimor skill list
--available`.
