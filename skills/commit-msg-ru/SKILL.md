# Сообщение коммита

1. Посмотри `git diff --staged` (или `git status`, если ничего не
   застейджено — скажи об этом, не выдумывай изменения).
2. Определи, ПОЧЕМУ сделано изменение, не только что изменилось — diff
   и так показывает что.
3. Формат: короткая строка (до ~70 символов) в повелительном наклонении
   («добавь», «исправь», «убери» — не «добавлен»/«добавляет»), при
   необходимости — пустая строка и абзац с деталями.
4. Один коммит — одна логическая перемена. Если diff явно смешивает
   несколько несвязанных изменений — скажи об этом прямо, предложи
   разбить, не притворяйся, что это одно изменение.
5. Не пиши сообщение, которое не можешь обосновать чтением реального
   diff — не проси и не предполагай контекст, которого нет в коде.
