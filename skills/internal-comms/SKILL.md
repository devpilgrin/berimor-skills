## Когда использовать этот скилл

Для написания внутренних коммуникаций используй этот скилл для:
- 3P-апдейтов (Progress, Plans, Problems — прогресс, планы, проблемы)
- Корпоративных рассылок
- Ответов на частые вопросы (FAQ)
- Статус-отчётов
- Апдейтов для руководства
- Апдейтов по проектам
- Отчётов об инцидентах

## Как использовать этот скилл

Чтобы написать любую внутреннюю коммуникацию:

1. **Определи тип коммуникации** из запроса
2. **Загрузи подходящий файл-руководство** из каталога `examples/`:
    - `examples/3p-updates.md` — для командных апдейтов Progress/Plans/Problems
    - `examples/company-newsletter.md` — для общекорпоративных рассылок
    - `examples/faq-answers.md` — для ответов на часто задаваемые вопросы
    - `examples/general-comms.md` — для всего остального, что явно не подходит под пункты выше
3. **Следуй конкретным инструкциям** из этого файла по форматированию, тону и сбору содержания

Если тип коммуникации не подходит ни под одно существующее руководство, попроси уточнить формат или дать больше контекста.
